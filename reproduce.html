Reproduce

Use the coefficients

Only Mathematica or Python is needed.

pp = Get["Coefficients/ProtonProton.wl"];
pp["Classes"][13]["LL"] /. {Nc -> 3, Nf -> 5, LR -> 0, LF -> 0, LFF -> 0, v -> 3/10, w -> 1/5} // N
pip install mpmath                                          # the only requirement
python3 Coefficients/evaluate.py --check                    # built-in 50-digit checks
python3 Coefficients/evaluate.py pp 13 LL 0.3 0.2 --digits 30

Run the calculation

With an agent (recommended)

An AI coding agent installs and checks the tools for you; you do not need to set them up one by one.

  1. Install Mathematica and clone the repository.
  2. Start the agent in the repository folder, with permission to run Mathematica and the external tools without approving each command: Codex with codex --approve-for-me (or “Approve for me” under /permissions at the start of a session); Claude Code in auto mode (Shift+Tab, or claude --permission-mode auto). The tools write to their user and temporary directories, which a restrictive sandbox blocks.
  3. Paste the setup prompt below. The agent installs FeynCalc, FeynArts, FORM, Tracer, Kira, Fermat and SubTropica and runs the toolchain check until it reports READY.
Set up FeynFacet on this machine. Install the tools it needs, following
docs/INSTALL.md (docs/INSTALL-macOS.md on a Mac; on Apple silicon, build
Kira with tools/install_kira.py as described there), and run
python3 feynfacet.py check --all-routes until it reports READY.
Ask me before anything that needs an administrator password.

The installation notes are what the agent follows. Mathematica and its license stay with you, and the agent asks before anything that needs your administrator password; on a Mac this includes Homebrew and Apple's Command Line Tools for Xcode. On Apple silicon the agent builds a patched Kira, since the Kira 3.1 release build can silently return wrong reductions there (details); this one-time build takes a few minutes.

When the check reports READY, open Start.nb and evaluate it, or ask the agent to run a process.

Manually

Install Mathematica with FeynCalc and FeynArts, FORM, Tracer, Kira (with Fermat) and SubTropica (with polymake) (installation notes; on Apple silicon, Kira needs the patched build). Then check the toolchain; the check performs small exact calculations with each tool, including eight Kira reductions, and reports what to fix:

python3 feynfacet.py check                # add --all-routes for FORM and Tracer

When it reports READY, open Start.nb and evaluate it: it loads the package and runs the lepton–quark process end to end. Every process can also be run from a terminal:

python3 Checks/run_process.py Processes/LeptonQuark
python3 Checks/run_process.py Processes/PartonicBorn                         # Born table, read by the proton–proton processes
python3 Checks/run_process.py Processes/Hadronic --set class=13              # FeynCalc route first
python3 Checks/run_process.py Processes/Hadronic --set class=13 --route FORM # compared with the FeynCalc squares

Each step runs in a fresh kernel; the results of a step are files that the next one reads. The process READMEs give the order for each process (the crossing check of the spin transfer, for instance, needs the double-transverse classes). The headless runner records evaluated cells and SHA-256 hashes of calculation sources and recorded inputs and outputs in Processes/<process>/Results/<step>[-<choices>].receipt.json. A receipt is marked complete after the last cell succeeds.
