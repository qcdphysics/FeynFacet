# Lepton–quark scattering: ℓ q → q + X at NLO

The NLO QCD correction to single-inclusive quark production in lepton–quark
scattering, for the spin average and for the double-longitudinal helicity
difference of the incoming lepton and quark.  The results are the hard
coefficients of Hinderer, Schlegel and Vogelsang, Phys. Rev. D 92 (2015)
014001 [arXiv:1505.06415] and Phys. Rev. D 96 (2017) 014002
[arXiv:1703.10872], and the notebooks end by comparing with them.

## Files

| File | What it does | Kernel time |
|---|---|---|
| `1-Amplitudes.wl` | FeynArts diagrams and amplitudes (Born, real, virtual, γq → qg), converted to plain records | 10 s |
| `2-Algebra-FeynCalc.wl` | Squared matrix elements with FeynCalc | 10 s |
| `2-Algebra-FORM.wl` | The same with FORM; the programs are in `form/` | 5 s |
| `2-Algebra-Tracer.wl` | The same with Tracer | 5 s |
| `3-Reduce.wl` | Reverse unitarity, Kira reduction (`kira/`), master integrals with SubTropica | 25 s |
| `4-Unpolarized.wl` | Threshold expansion, virtual term, collinear counterterms, finite coefficient, comparison with arXiv:1505.06415 | 2 min |
| `5-Polarized.wl` | The same for the helicity difference, comparison with arXiv:1703.10872 | 2 min |
| `form/` | FORM programs: `common.h` (conjugation, spin sums, HVBM γ₅), `Born.frm`, `Real.frm`, `Photon.frm`, `Virtual.frm` |
| `kira/` | Kira integral families and jobs for the real (cut) and virtual integrals |
| `reference/` | The published coefficients, transcribed for the final comparison only |
| `*.nb` | Notebook versions of the `.wl` files, generated by `Checks/make_notebooks.wls` |
| `Results/` | Created when the notebooks run (not part of the repository) |

## How to run

Open the files in Mathematica in the order 1, 2 (any one of the three
routes), 3, 4, 5, each in a fresh kernel, and evaluate the cells from top to
bottom (`Shift+Enter`).  Steps 3, 4 and 5 begin with
`route = "FeynCalc"`; change it to `"FORM"` or `"Tracer"` to continue from
another route's step 2.  Every intermediate result is saved under
`Results/<route>/`, so a step can be rerun on its own.

Headless, from the repository root:

```sh
python Checks/run_process.py Processes/LeptonQuark --route FeynCalc
python Checks/run_process.py Processes/LeptonQuark --route FORM
python Checks/run_process.py Processes/LeptonQuark --route Tracer
```

Each run stops at the first failed check.  A completed run means: the
amplitudes were generated, the Born squares agree with their textbook form,
all master integrals passed their checks, the double and single poles
cancelled, and the finite coefficients agree exactly with the published
ones (`LiteratureDifference -> {0, 0, 0, 0}` in `Results/<route>/Unpolarized.wl`
and `Polarized.wl`).

## What is checked, and where

Every check is a `Require[...]` cell that aborts the notebook with a message
if it fails; the quantity it tests is displayed next to it.

| Step | Check |
|---|---|
| 1 | number of diagrams per process (1, 2, 3, 1, 2) |
| 2 (all routes) | Born squares equal 2 e⁴ e_q² [(s²+u²)/t² − ε] and 2 e⁴ e_q² (s²−u²)/t²; the three routes write the same file format and can be compared with each other |
| 2 (FORM) | the explicit HVBM γ₅ reproduces Tr[γᵃγᵇγᶜγᵈγ₅] = −4i ε^{abcd} |
| 3 | partial fractions reproduce the matrix element; every integral reduced; two-body phase-space volumes and the loop bubble equal their Γ-function forms; the angular masters agree with their hypergeometric closed forms and with direct numerical integration |
| 4, 5 | Born hard parts equal the textbook forms; double poles cancel between real and virtual; single poles cancel between real, virtual and the three collinear counterterms (table displayed); the finite coefficient equals the published one, symbolically and at three numerical points |

To compare the routes, run step 2 for two of them and `Get` the two
`Results/<route>/Algebra.wl` files; their entries agree exactly (up to
s + t + u = 0 in the Born terms).

## Conventions in brief

Momenta l (lepton), k (quark) incoming; p observed quark; lp, r unobserved.
Invariants s = 2 l·k, t = −2 k·p, u = −2 l·p, v = 1 + t/s, w = −u/(s+t),
s4 = s v (1 − w).  The hard coefficient is σ(s, v, w) = s E dσ/d³p; at NLO

    σ = σ_Born δ(1−w) + CF α² e_q² α_s/(π s v w) [ R + B D0 + C D1 + A δ(1−w) ]

with D0 = [1/(1−w)]₊ and D1 = [ln(1−w)/(1−w)]₊, where B, C, A are the
coefficients at w = 1 and R carries the factor 1/w of the papers.  The papers
put their prefactor 1/w in front of the distributions as well, and the 2015
paper's coefficient of D0 depends on w; `reference/` transcribes them exactly
as printed and the comparison cells bring both forms to the same basis with
the distribution identity f(w) D0 = f(1) D0 + (f(w) − f(1))/(1−w).  Dimensional regularization
with D = 4 − 2ε, MSbar, HVBM γ₅ with the finite helicity-restoring term
for the polarized incoming quark, all factorization scales equal to muR.
See `docs/CONVENTIONS.md` for the complete list.
