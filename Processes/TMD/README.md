# TMD beam functions and soft function at NLO

The NLO matching coefficients I_qq, I_qg, I_gq, I_gg of the quark and gluon
TMD beam functions, the NLO soft function for quarks and gluons, and from them
the perturbative matching coefficients f_ij = I_ij √S_i of the
soft-subtracted TMD parton distributions, all with the exponential rapidity
regulator of Li, Neill and Zhu.  The results are compared with the ancillary
tables of Luo, Yang, Zhu and Zhu, JHEP 06 (2021) 115
[arXiv:2012.03256], and agree exactly.

Unlike the other processes these are matrix elements of light-cone operators
with Wilson lines, not cross sections.  The point of this process is to show
how such operator matrix elements are generated with FeynArts from a model in
which Wilson lines and operator insertions are ordinary fields.

## How to run

As for the other processes: open the files in Mathematica in the order 1, 2
(any one route), 3, 4, 5, each in a fresh kernel, and evaluate from top to
bottom; or, from `Start.nb`, `RunSteps["TMD", "FeynCalc"]` (also `"FORM"`,
`"Tracer"`), or from a terminal

```sh
python Checks/run_process.py Processes/TMD --route FeynCalc
```

Steps 4 and 5 begin with `route = "FeynCalc"`; change it to continue from
another route's step 2.  Step 3 does not depend on the route.

## Conventions

n, nb light-like with n.nb = 2; the incoming parton p is along nb, so n.p is
its large component and γ⁺ = n-slash; the Wilson lines of the beam operators
run along n to +∞ (future pointing); the emitted parton k has n.k = (1−x) n.p
and transverse momentum kT2 = (n.k)(nb.k).  The beam function is normalized to
δ(1−x) at lowest order, the soft function to 1; as = αs/(4π); Lp =
ln(b² μ²/b0²), b0 = 2 e^{−γ_E}; LQ = 2 ln(x n.p/ν); Lν = ln(ν²/μ²); Lh = LQ +
Lν.  The rapidity regulator is exp[−τ e^{−γ_E}(n.k + nb.k)] with ν = 1/τ, τ →
0 before ε → 0; the zero-bin subtraction divides by the bare soft function.
Details in `docs/CONVENTIONS.md`.

## Algebra and integral representation

The FeynCalc route contracts the specified polarization tensors before expanding
Dirac traces. The Tracer route first combines scalar coefficients multiplying
identical inactive traces. FORM already sorts the summed amplitudes and the
polarization and colour contractions before evaluating its traces. These
changes preserve the operator projectors, light-cone kinematics and dimension.

The measured integral system is small: two target integrals reduce to three
finite Euler masters. The target and master labels are checked explicitly
before substituting the master values. There is no hadronic six-invariant
family map in this calculation. Rapidity regulation, soft-overlap subtraction
and the master-integral formulas are those described above.
